🔐 Qu’est-ce que JAAS ?
⚙ JAAS est une API Java standard permettant de gérer :
●

l’authentification (qui est l’utilisateur ?)

●

l’autorisation (a-t-il le droit ?)

JAAS repose sur une architecture modulaire.

🧠 Les concepts clés de JAAS
1. LoginModule
C’est le composant responsable de la vérification des credentials.
Il peut :
●

vérifier un mot de passe en base

●

valider un token

●

interroger un LDAP

●

etc.

🧠 Les concepts clés de JAAS
2. LoginContext
C’est le point d’entrée du processus d’authentification.

🧠 Les concepts clés de JAAS
3. Subject
Après authentification, JAAS crée un Subject, ce Subject contient :
●
●

des Principal (identité)
éventuellement des rôles

Exemple :

Un Principal représente une identité ou un rôle.
●
●

UserPrincipal
RolePrincipal
