🧩JAX-RS – L’implémentation REST en Java
⚙ Qu’est-ce que JAX-RS ?
JAX-RS (Java API for RESTful Web Services) est une spécification Java permettant de créer
des services REST.
Comme JPA :
●

JAX-RS est une API standard

●

Elle nécessite une implémentation (ex : Jersey, RESTEasy)
